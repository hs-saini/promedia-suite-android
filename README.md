# ProMedia Suite for Android

ProMedia Suite combines local image editing and document tools in one Android app. Images are processed on your device; Firebase account and premium features require a separately configured project.

## Downloads

- [ARM64 APK for most modern Android phones](https://github.com/hs-saini/promedia-suite-android/releases/latest/download/ProMediaSuite.apk)
- [ARMv7 APK for older 32-bit devices](https://github.com/hs-saini/promedia-suite-android/releases/latest/download/ProMediaSuite-armv7.apk)

Download the APK on your phone, open it, and approve Android's install-from-this-source prompt for your browser or file manager. If Android reports that the app is incompatible, use the other architecture variant.

This public repository contains only installation instructions and signed release APKs; it does not contain the ProMedia Suite source code or private admin panel.
